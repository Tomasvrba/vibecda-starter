# Event archive

Create one folder per event. Preserve the confirmed event.json, public rules and
rubrics, project URLs and submitted commits, final results, approved photos, and a
short retrospective. Keep raw judge scores, contact information, registration
data, and credentials out of this public archive and Git.

For 2026-11-vibecda, start from organizer/event.json after confirmation. Record
the final judging decisions and any tie resolution before publishing results.
