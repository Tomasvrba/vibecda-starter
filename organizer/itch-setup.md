## Ready-to-paste description

Welcome to vibeCDA: build a game with AI in a weekend! This is a friendly,
beginner-welcoming game jam in Coeur d'Alene, Idaho, November 13–15, 2026.

Register, read the full schedule, and check venue updates at https://vibecda.com.
Registering for the event and submitting a project to the jam are separate steps.

Build solo or in a team of up to five. Freeplay is open to any game idea; Wizards
and Lizards is the Halloween-themed track. GTA Cda is an ongoing shared community
build and is not judged. Follow the organizer's track-specific submission links.

Use any engine or development tools. The prepared browser-game starter is optional.
Bring your own AI account; the event does not provide a shared subscription or API
key. Credit assets and disclose AI use. Only use photos, voices, code, and assets
you have permission to include.

Submit by noon Pacific on Sunday November 15. Upload a working browser build or
downloadable game, add controls, supported platforms, screenshots, credits, and
your team information. Include a demo video if judges may have trouble running it.
Then use the jam's Submit your project button: uploading to an itch.io page alone
does not enter the jam. Save the submitted code commit/build before judging.

Each track has five criteria, scored 1–5 with equal weight. Awards are at 6pm
Sunday. Attendance at Sunday's open play and awards is required for prizes under
the current event rules. Sunday venue is still marked to be confirmed on the site.
See the event site for the complete rules and venue updates.

## Criteria

Freeplay: It's playable; Fun factor; Learning and growth; Idea and personality;
Demo. Each contributes 20%. Ties: Learning and growth, then judges' majority vote.

Wizards and Lizards: Creativity and originality; Quality of execution; Halloween
theme fit; Art, sound, and atmosphere; Fun and replay. Each contributes 20%.
Ties: Creativity, then Execution, then judges' majority vote.

itch.io's automatic overall score averages the criteria. Hosts must apply the
announced tie policy when declaring awards; automated sorting alone isn't the
tie decision. The local scoring tool is an optional audit/manual-ranking route.
