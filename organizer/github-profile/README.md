# vibeCDA

Community game jams and hackathons in Coeur d'Alene, Idaho.
Build games with AI, learn something new, and share what you make.

- [Event website and registration](https://vibecda.com)
- [Participant guide](https://vibecda.github.io/vibecda-starter/): dates, setup,
  tools, editor connections, and submission instructions.
- [Game starter](https://github.com/VibeCdA/vibecda-starter): optional Phaser,
  Vite, and TypeScript template with a prepared Codespaces environment.
- [Community help and teammates](https://github.com/VibeCdA/vibecda-starter/discussions)
- [Freeplay jam](https://itch.io/jam/vibecda-2026-freeplay)
- [Wizards and Lizards jam](https://itch.io/jam/vibecda-2026-wizards-and-lizards)

Beginners welcome. Use your own AI account; the starter includes tools, while
subscriptions and usage allowances belong to each participant. Native-engine
projects are welcome too.
