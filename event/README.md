# Public event information

`event.json` contains the public schedule, track criteria, and participant links
used to build the event guide. It contains no judge assignments, raw scores,
contacts, or internal operations notes.

Participants should make their games in `src/` and `public/`; you do not need to
edit this configuration. For the event schedule and submissions, use the
[participant guide](https://vibecda.github.io/vibecda-starter/).
